회의주제 화분 흙 상태 알림 서비스 프로젝트 계획 수립
회의내용

■ 프로젝트 소개: 화분 흙에 꽂아 둔 센서가 흙의 수분을 자동으로 재서 보내 주면, 웹사이트가 흙의 상태를 판정하고 지금 무엇을 해야 하는지 알려 주는 서비스를 만든다. 서비스 이름은 아직 정하지 않았으며, 이 회의록에서는 '화분 흙 상태 알림 서비스'로 부른다.

■ 만드는 이유: 집에서 화분을 키우는 사람은 흙 속의 상태를 눈으로 보기 어렵기 때문에 물을 줄 시기를 놓쳐 식물을 말리거나, 반대로 물을 너무 자주 줘서 뿌리를 썩게 만드는 경우가 많다. 흙의 수분을 숫자로 확인하고 그에 맞는 안내를 받으면 경험이 적은 사람도 화분을 쉽게 관리할 수 있다.

■ 사용 대상: 집이나 사무실에서 화분을 키우는 일반인을 대상으로 한다. 식물에 관한 전문 지식이 없어도 화면만 보고 바로 이해할 수 있도록 만든다.

■ 서비스 이용 순서

  1. 사용자가 센서를 화분의 흙에 꽂는다.
  2. 웹사이트에 로그인하고, 센서를 꽂은 화분을 '내 화분'으로 등록한다.
  3. 센서가 일정한 시간마다 흙의 수분을 재서 웹사이트로 자동 전송한다.
  4. 사용자는 웹사이트에서 화분의 현재 상태와 관리 안내를 확인한다.
  5. 안내에 따라 물을 주거나 물 주기를 멈춘다.
  6. 지난 기록을 열어 흙 상태가 어떻게 변해 왔는지 비교한다.

■ 주요 기능

  1. 흙 상태 판정: 센서가 보낸 수분 값을 바탕으로 흙의 상태를 세 단계로 보여 준다.
    • 건조: 흙이 말라서 물이 필요한 상태
    • 적당: 수분이 알맞아 그대로 두면 되는 상태
    • 과습: 물이 너무 많아 뿌리가 상할 수 있는 상태
  2. 관리 방법 안내: 판정 결과에 맞춰 "지금 물을 주세요", "물 주기를 멈추고 바람이 잘 통하는 곳에 두세요"처럼 사용자가 바로 따라 할 수 있는 안내 문구를 보여 준다.
  3. 이전 기록과 비교: 날짜별 수분 변화를 그래프로 보여 주어, 물을 준 뒤에 흙이 얼마나 빨리 마르는지와 상태가 좋아졌는지를 확인할 수 있게 한다.
  4. 개인 기록 관리: 로그인한 사용자는 자신이 등록한 화분의 기록만 볼 수 있고, 다른 사람의 기록은 볼 수 없다.

■ 화면 구성

  1. 로그인 화면
  2. 내 화분 목록 화면: 등록한 화분과 각 화분의 현재 상태
  3. 화분 상세 화면: 현재 수분 상태, 판정 결과, 관리 안내
  4. 기록 화면: 날짜별 수분 변화 그래프와 지난 판정 결과

■ 이번 프로젝트에서 제외하는 범위: 개발 기간이 약 3주로 짧기 때문에, 흙의 수분 하나만 측정해서 판정과 안내까지 완성하는 데 집중한다. 아래 항목은 이번 프로젝트에서 만들지 않고, 기간이 남거나 이후에 확장할 때 검토한다.

  1. 온도, 빛의 양, 산도, 영양분 측정
  2. 화분에 맞는 식물 추천
  3. 흙 사진을 찍어서 상태를 판단하는 기능
  4. 물을 자동으로 주는 장치

■ 개발 일정 (2026.11.05 ~ 2026.11.28)

  1. 1주차 (11.05 ~ 11.11): 계획 확정, 화면 구성 설계, 센서 준비와 측정 시험
  2. 2주차 (11.12 ~ 11.18): 센서 값 자동 전송, 로그인과 화분 등록, 기본 화면 제작
  3. 3주차 (11.19 ~ 11.25): 흙 상태 판정, 관리 안내, 기록 비교 기능 제작 후 전체 연결
  4. 마무리 (11.26 ~ 11.28): 실제 화분으로 시험, 오류 수정, 발표 준비

■ 완성 기준: 아래 세 가지가 실제 화분에서 확인되면 완성으로 본다.

  1. 센서를 꽂은 화분의 수분 상태가 사람이 입력하지 않아도 웹사이트에 표시됨
  2. 흙을 말리거나 물을 주었을 때 판정 결과와 안내 문구가 그에 맞게 바뀜
  3. 며칠 동안 쌓인 기록을 그래프로 비교할 수 있음

■ 다음 회의까지 결정할 사항

  1. 서비스 이름
  2. 팀원별 역할 분담
  3. 센서가 수분을 재서 보내는 간격 (예: 10분마다, 1시간마다)
  4. 건조, 적당, 과습을 나누는 기준
    • 식물마다 좋아하는 수분이 다르므로, 기준을 하나로 둘지 식물 종류별로 나눌지 정함
  5. 흙 상태 판정에 AI를 활용할지 여부
  6. 시험에 사용할 화분의 개수와 식물 종류
