회의주제 화분 흙 상태 알림 서비스 기획서
회의내용

한 줄 소개
화분 흙에 작은 센서를 꽂아 두면, 웹사이트가 흙이 마른지 젖은지를 알아서 확인하고 "지금 물을 주세요"처럼 지금 해야 할 일을 알려 준다.

■ 서비스 이름

정식 이름은 아직 정하지 않았으며, 이 기획서에서는 '화분 흙 상태 알림 서비스'로 부른다.

■ 만드는 이유

  1. 흙 속은 눈으로 보이지 않는다: 겉흙은 말라 보여도 속은 젖어 있거나, 반대로 겉은 촉촉해도 속은 말라 있는 경우가 많아서 물을 줄 때를 짐작으로 정하게 된다.
  2. 식물이 상하는 가장 흔한 원인은 물 관리다: 바빠서 물 주기를 잊으면 식물이 말라 버리고, 걱정이 되어 물을 너무 자주 주면 뿌리가 썩는다.
  3. 처음 키우는 사람은 기준을 모른다: "언제, 얼마나 물을 줘야 하는지"를 판단할 경험이 없어서 화분을 키우다가 포기하는 경우가 많다.

이 서비스는 흙의 상태를 대신 확인해 주고 할 일을 쉬운 말로 알려 주기 때문에, 경험이 적은 사람도 화분을 오래 건강하게 키울 수 있다.

■ 이 서비스를 쓰는 사람

  1. 일반 사용자: 집이나 사무실에서 화분을 키우는 사람으로, 식물에 관한 지식이 없어도 화면만 보고 바로 이해할 수 있어야 한다.
  2. 관리자: 서비스를 운영하는 우리 팀으로, 전체 사용자와 화분, 센서의 상태를 한눈에 확인하고 게시판을 관리한다.

■ 무엇을 만드는가

화분에 꽂는 센서와, 센서가 알려 준 흙 상태를 보여 주는 웹사이트를 함께 만든다. 센서는 흙이 얼마나 젖어 있는지를 일정한 시간마다 재서 웹사이트로 자동으로 보내므로, 사용자가 직접 무언가를 입력할 필요가 없다.

웹사이트는 흙의 상태를 아래 세 단계로 나누어 보여 준다.

  1. 건조: 흙이 말라서 물이 필요한 상태 → "지금 물을 주세요"
  2. 적당: 수분이 알맞은 상태 → "지금처럼 두면 돼요"
  3. 과습: 물이 너무 많아 뿌리가 상할 수 있는 상태 → "물 주기를 멈추고 바람이 잘 통하는 곳에 두세요"

■ 사용하는 순서

  1. 센서를 화분의 흙에 꽂는다.
  2. 웹사이트에 로그인하고, 센서에 어떤 식물인지 등록한다.
  3. 센서가 흙 상태를 자동으로 재서 웹사이트로 보낸다.
  4. 사용자는 웹사이트에서 화분의 상태와 해야 할 일을 확인한다.
  5. 물이 부족한 화분이 생기면 화면에 알림이 뜬다.
  6. 안내에 따라 물을 주거나 물 주기를 멈춘다.

■ 주요 기능

  1. 내 화분 한눈에 보기: 화분마다 카드 한 장으로 보여 주며, 카드에는 흙 상태와 센서의 연결 여부, 센서 배터리가 얼마나 남았는지가 표시된다.
  2. 할 일 안내: 숫자 대신 "지금 물을 주세요"처럼 바로 따라 할 수 있는 문장으로 알려 준다.
  3. 물 부족 알림: 물이 필요한 화분이 있으면 화면에 알림 창을 띄워 놓치지 않게 한다.
  4. 지난 기록 보기: 날짜별로 흙이 얼마나 젖어 있었는지를 그래프로 보여 주므로, 물을 준 뒤 흙이 얼마나 빨리 마르는지 알 수 있다.
  5. 성장 사진 기록: 식물 사진을 찍어 올려 두면, 식물이 얼마나 자랐는지를 시간 순서대로 볼 수 있다.
  6. 커뮤니티: 다른 사용자에게 키우는 방법을 묻고 답하거나, 정보를 나누고 내 식물을 자랑할 수 있는 게시판이다.
  7. 개인 기록 보호: 각 사용자는 자신이 등록한 화분의 기록만 볼 수 있다.

■ 화면 구성

  1. 로그인과 회원가입: 카카오톡 또는 이메일로 로그인
  2. 메인 화면: 내 화분 카드 목록과 물 부족 알림
  3. 화분 상세 화면: 흙 상태 그래프, 성장 사진, 장치 관리 버튼
  4. 장치 관리 화면: 센서에 어떤 식물인지 등록
  5. 커뮤니티 화면: 질문과 답변, 정보 공유, 자랑 게시판
  6. 마이페이지: 내가 쓴 글과 댓글
  7. 관리자 화면: 전체 통계, 사용자 관리, 게시판 관리

휴대폰과 컴퓨터 어디서 보아도 편하도록 두 화면 크기에 모두 맞춰 만든다.

■ 이번에 만들지 않는 것

개발 기간이 약 3주로 짧기 때문에, 흙이 얼마나 젖어 있는지 하나만 재서 알려 주는 기능을 완성하는 데 집중한다. 아래 항목은 이후에 확장할 때 검토한다.

  1. 온도, 햇빛의 양, 흙의 산성도, 영양분 측정
  2. 화분에 맞는 식물 추천
  3. 흙 사진만 보고 상태를 판단하는 기능
  4. 물을 자동으로 주는 장치

■ 역할 분담

  1. 양현지: 사용자가 보는 웹사이트 화면 제작
  2. 김민경: 화면 뒤에서 기록을 저장하고 처리하는 기능 제작
  3. 이선학: 센서 장치 제작, 서버 관리와 기술 지원

■ 일정 (2026.11.05 ~ 2026.11.28)

  1. 1주차 (11.05 ~ 11.11): 기획 확정, 화면 설계, 센서 준비와 측정 시험
  2. 2주차 (11.12 ~ 11.18): 센서 값 자동 전송, 로그인과 화분 등록, 기본 화면 제작
  3. 3주차 (11.19 ~ 11.25): 흙 상태 판정과 안내, 기록 그래프, 커뮤니티 제작
  4. 마무리 (11.26 ~ 11.28): 실제 화분으로 시험, 오류 수정, 발표 준비

■ 완성 기준

아래 세 가지를 실제 화분에서 확인하면 완성으로 본다.

  1. 사람이 입력하지 않아도 센서를 꽂은 화분의 흙 상태가 웹사이트에 표시됨
  2. 흙을 말리거나 물을 주면 화면의 판정과 안내 문구가 그에 맞게 바뀜
  3. 며칠 동안 쌓인 기록을 그래프로 비교할 수 있음

■ 기대 효과

  1. 물을 주는 시기를 놓치거나 물을 너무 많이 줘서 식물이 상하는 일이 줄어든다.
  2. 식물을 처음 키우는 사람도 부담 없이 화분을 관리할 수 있다.
  3. 기록과 성장 사진이 쌓이면서 내 식물의 관리 습관을 스스로 돌아볼 수 있다.
  4. 커뮤니티를 통해 사용자끼리 키우는 방법을 나누며 서비스를 계속 이용하게 된다.

■ 아직 정하지 않은 사항

  1. 서비스 이름
  2. 센서가 흙 상태를 재서 보내는 간격 (예: 10분마다, 1시간마다)
  3. 건조, 적당, 과습을 나누는 기준
    • 식물마다 좋아하는 수분이 다르므로, 기준을 하나로 둘지 식물 종류별로 나눌지 정함
  4. 흙 상태를 판단할 때 AI를 활용할지 여부
  5. 시험에 사용할 화분의 개수와 식물 종류
